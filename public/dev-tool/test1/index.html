    个人站与博客园同步方案#

    要实现「一份博客源码，同时支持个人站 + 博客园发布」，核心思路是 「统一内容源 + 格式兼容处理 + 双端发布自动化」。结合技术博客的特性（Markdown 优先、代码高亮、图片展示），推荐以下方案，兼顾灵活性、易用性和维护效率：

    一、整体架构设计#

    核心逻辑：用 Markdown 作为唯一内容源（存储在 Git 仓库），通过「静态博客框架」构建个人站，再通过「格式转换 + 自动化工具」同步到博客园，避免重复编辑。

    （图床统一存储图片，双端共用）

    关键选型#

    组件 推荐方案 核心作用
    个人博客框架 Hugo（优先）/ Hexo / Jekyll 快速生成静态博客，支持自定义主题、代码高亮
    内容存储 Git 仓库（GitHub/Gitee） 版本控制，统一管理 Markdown 源码
    图片存储 图床（PicGo + 阿里云 OSS/GitHub 图床） 统一图片链接，双端均可访问
    格式兼容处理 Pandoc + 自定义脚本 解决 Markdown 语法差异（如代码块、表格）
    博客园同步工具 cnblog-publisher（Python 库）/ 手动插件 自动推送 Markdown 到博客园后台
    个人站部署 GitHub Pages / Vercel / Netlify 免费托管静态博客，支持自定义域名

    二、分步实现指南#

    第一步：搭建个人博客（以 Hugo 为例，最快上手）#

    Hugo 是Go 编写的静态框架，构建速度极快，支持 Markdown 原生语法，适合技术博客。

    1. 环境准备#

    • 安装 Hugo：brew install hugo（Mac）/ 官网下载（Windows/Linux）
    • 初始化博客： 
      • hugo new site my-blog && cd my-blog
git init  # 初始化 Git 仓库（后续管理 Markdown 源码）
    • 选择主题（推荐技术博客主题）： 
      • # 示例：安装 LoveIt 主题（支持代码高亮、数学公式、目录）
git submodule add https://github.com/dillonzq/LoveIt.git themes/LoveIt
    • 配置 config.toml（主题配置、站点信息、自定义域名等，参考主题文档）。

    2. 编写博客规范#

    • 所有博客放在 content/posts/ 目录下，文件格式为 xxx.md。
    • 统一使用 Front Matter 定义元信息（双端共用），示例： 
      • ---
title: "Go 并发编程之 Goroutine 原理"  # 标题（双端共用）
date: 2025-12-03T10:00:00+08:00       # 发布时间
tags: ["Go", "并发"]                   # 标签（博客园同步时自动提取）
categories: ["技术总结"]               # 分类（博客园同步时自动提取）
draft: false                           # 是否草稿（个人站不发布草稿，同步时过滤）
description: "深入讲解 Goroutine 的调度模型和使用场景"  # 摘要
---

# 正文内容（标准 Markdown 语法）
这是博客正文，支持：
- 代码块（```go ... ```）
- 图片（）
- 表格、数学公式等
    • 本地预览：hugo server -D，访问 http://localhost:1313 查看效果。

    3. 部署个人站到 GitHub Pages#

    • 生成静态文件：hugo（输出到 public/ 目录）。
    • 关联 GitHub 仓库（新建 my-blog 仓库），推送源码： 
      • git add . && git commit -m "初始化博客"
git remote add origin https://github.com/你的用户名/my-blog.git
git push -u origin main
    • 自动化部署（GitHub Actions）：
      • 在博客根目录创建 .github/workflows/deploy.yml，内容如下： 
        1. name: Deploy Hugo Site to GitHub Pages
on:
  push:
    branches: [main]  # 推送 main 分支时触发
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          submodules: true  # 拉取主题子模块
          fetch-depth: 0
      - name: Setup Hugo
        uses: peaceiris/actions-hugo@v3
        with:
          hugo-version: "latest"
      - name: Build
        run: hugo --minify  # 构建静态文件
      - name: Deploy
        uses: peaceiris/actions-gh-pages@v4
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./public  # 部署 public 目录到 gh-pages 分支
      • 推送后，GitHub 会自动构建并部署到 用户名.github.io/my-blog，也可绑定自定义域名（在仓库 Settings -> Pages 配置）。

    第二步：统一内容源与格式兼容#

    核心目标：让 Markdown 同时适配「个人站（Hugo）」和「博客园」，避免语法差异导致的格式错乱。

    1. 图片统一存储（图床）#

    • 问题：本地图片路径（../images/xxx.png）在博客园无法访问。
    • 解决方案：使用图床，将图片上传后获取「公开绝对链接」，Markdown 中直接引用。
    • 工具：PicGo（桌面端），支持一键上传到阿里云 OSS、GitHub 图床、SM.MS 等。
      • 配置示例（GitHub 图床）：
        • 新建 GitHub 仓库（如 blog-images），生成 Personal Access Token（勾选 repo 权限）。
        • PicGo 中选择「GitHub 图床」，填写仓库名、分支、Token、存储路径（如 2025/12/）。
      • 使用：截图后复制到剪贴板，PicGo 自动上传并生成链接，直接粘贴到 Markdown。

    2. Markdown 语法兼容处理#

    博客园支持 Markdown 但有部分语法差异，需统一为「双端兼容语法」：

    场景 兼容写法（双端通用） 避免写法（仅个人站支持）
    代码块 go func main() {} {% codeblock lang:go %}…{% endcodeblock %}（Hugo 短代码）
    表格 标准 Markdown 表格（` 表头
    数学公式 用 $E=mc^2$（Hugo 需启用 MathJax，博客园后台开启「数学公式支持」） Hugo 专属数学公式短代码
    目录 博客园自动生成（无需写 ），个人站用（主题支持） 直接写 （双端行为不一致）
